# codex-autofix-agent-demo

[→ Try the live agent](about:blank)

This demo is based on my another repo: https://github.com/RaphaelRevivor/LRUCache, which is a lightweight, generic Least Recently Used (LRU) cache implementation in C++ using templates.

This agent reads CodeQL alerts, fetches the relevant code from GitHub,
and proposes safe, minimal patches using OpenAI Codex.
It demonstrates autonomous reasoning and tool integration akin to Copilot Autofix.
